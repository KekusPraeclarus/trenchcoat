## TLDR

Fomo integration is an authorized, read-only Playwright collector against
[fomo.family](https://fomo.family/). There is no official FOMO Labs public API.
The previous unofficial third-party bridge is removed from this repo.

Primary value: dated feed/trending/leaderboard observations for research-queue
triggers, wallet nomination (exact addresses only), and dual-track X-source
review (shiller outcomes vs narrative utility). Kill switch: `fomo.enabled=false`.

See [docs/knowledge/fomo-family.md](../docs/knowledge/fomo-family.md) and
[ops/fafo-fomo/SHADOW-CANARY.md](fafo-fomo/SHADOW-CANARY.md).
